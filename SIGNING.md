# Подписанная сборка RxLauncher для Windows

Релизная сборка намеренно блокируется без доверенного RSA-сертификата подписи кода. Самоподписанный сертификат не подходит: SmartScreen и Smart App Control не считают его доверенным.

## Необходимые данные

- PFX/P12-сертификат Code Signing от доверенного центра сертификации;
- пароль сертификата;
- полный `Subject DN` сертификата (например, `CN=..., O=..., L=..., C=...`);
- действующая цепочка доверия Windows и доступ к серверу метки времени.
- Windows SDK с `signtool.exe` для собственных C#-установщика и деинсталлятора. При нестандартной установке задайте абсолютный `RX_SIGNTOOL_PATH`.

Вместо экспортируемого PFX можно использовать сертификат на аппаратном токене/в хранилище Windows. Для него задаётся `RXLAUNCHER_CERTIFICATE_SHA1` — 40-значный thumbprint сертификата.

Сертификат и пароль нельзя добавлять в репозиторий. Они передаются только через переменные окружения:

```powershell
$env:WIN_CSC_LINK = 'C:\secure\RxLauncher-Code-Signing.pfx'
$securePassword = Read-Host 'Пароль сертификата' -AsSecureString
$env:WIN_CSC_KEY_PASSWORD = [System.Net.NetworkCredential]::new('', $securePassword).Password
$env:RXLAUNCHER_PUBLISHER_NAME = 'CN=ТОЧНЫЙ SUBJECT, O=ОРГАНИЗАЦИЯ, C=СТРАНА'
npm run build-win
Remove-Item Env:WIN_CSC_KEY_PASSWORD
```

Вариант с аппаратным токеном или хранилищем Windows:

```powershell
$env:RXLAUNCHER_CERTIFICATE_SHA1 = '40-ЗНАЧНЫЙ-THUMBPRINT-БЕЗ-ПРОБЕЛОВ'
$env:RXLAUNCHER_PUBLISHER_NAME = 'CN=ТОЧНЫЙ SUBJECT, O=ОРГАНИЗАЦИЯ, C=СТРАНА'
npm run build-win
```

`npm run build-win` выполняет обязательные этапы:

1. собирает и подписывает собственный `RxUninstall.exe`;
2. electron-builder подписывает приложение, вспомогательный elevating-процесс и NSIS-установщик; `beforePack` отклоняет сборку без встроенного ожидаемого издателя и подписанного деинсталлятора;
3. полный Subject DN записывается и в `app-update.yml`, и внутрь защищённого `app.asar`; при запуске значения обязаны совпасть, поэтому подмена внешнего файла конфигурации не меняет доверенного издателя;
4. проверяет подпись NSIS-ядра перед встраиванием в C#-обёртку, собирает и подписывает внешний `RxLauncher Setup <версия>.exe`;
5. `scripts/verify-windows-signatures.ps1` проверяет доверие, единого издателя и метку времени у всех пяти релизных файлов: приложения, elevate, NSIS-ядра, внешнего Setup и собственного деинсталлятора.

При отсутствии сертификата, неверном пароле, недоверенной подписи или отсутствии метки времени сборка завершается ошибкой и неподписанный установщик не считается релизом.

Для собственных C#-файлов PFX передаётся как путь к локальному файлу; удалённый URL/base64 в `WIN_CSC_LINK` здесь не поддерживается. Пароль и сертификат не попадают в репозиторий. `npm run build-installer` также требует корректно подписанного NSIS-ядра и подписывает результат; `--no-payload` предназначен только для просмотра дизайна. Ранее собранные EXE от этих изменений автоматически не подписываются.
